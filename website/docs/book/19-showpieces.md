# Showpieces

Short programs that do something you cannot write this way elsewhere, each the
capability of an earlier chapter pushed until it shows.

This chapter is being rewritten. The earlier showpieces relied on experimental
APIs that have since been removed; new ones will be added as the corresponding
capabilities are reattached.
