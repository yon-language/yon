# The category of each word and each spelling of the lexer, for the highlighters.
# A source, written by hand, in one place: tools/gen_highlighters.py reads it with
# regression/GRAMMAR.tokens and stops if a live word or spelling of the lexer has no category, or
# if a line here names a word or a spelling the lexer does not give.
#
# Categories of the words:
#   declaration  heads a declaration and binds the name after it (VS Code: storage.type, and the
#                declarations rule that colors the name)
#   storage      a word of the structure of a declaration (storage.type)
#   control      the flow of a body (keyword.control)
#   binding      a binding (keyword.other.binding)
#   word         a word that relates two parts (keyword.operator.word)
#   constant     a constant of the language (constant.language)
#   boolean      true and false (constant.language; Prism: boolean)
#   hott         a form of paths and of the cubical layer (keyword.other.hott)
#   type         a type of the language (support.type.primitive)
# Categories of the spellings:
#   operator, operator-heyting (the intuitionistic connectives and bit operators), punctuation (not
#   colored), and a word category for a glyph that is a word (Π Σ ∀ ∃).
